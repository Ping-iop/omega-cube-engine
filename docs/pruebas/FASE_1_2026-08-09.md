Fecha: 2026-08-09 23:15 UTC-5

## Implementación
- `omega_cube/embeddings.py` — SemanticEmbedder: embeddings reales 768d vía
  nomic-embed-text (ollama:11434), cache en `memory/semantic_embeddings.json`.
  Reemplaza los embeddings ALEATORIOS del TurboVec bridge (fallback con similitudes ~0.0).
- `omega_cube/cube_move.py` — CubeMover: Fase 2D (matriz V @ q) + Fase 3D
  (giros de cara por asociaciones cruzadas, 1 nivel) + validación.

## Calibración de τ (obligatoria según plan, sección F1)
Distribución de scores con datos reales (49 nodos):

| query | top-1 | #≥0.55 | #≥0.60 | #≥0.65 |
|---|---|---|---|---|
| EXISTE (luz) | +0.787 | 4 | 1 | 1 |
| EXISTE (evony) | +0.728 | 21 | 12 | 6 |

| NO EXISTE (pastel) | +0.595 | 5 | 0 | 0 |
| NO EXISTE (francia) | +0.594 | 3 | 0 | 0 |

**τ=0.60 elegido**: techo de temas inexistentes = 0.595 (ambos); todos los
temas existentes tienen ≥1 nodo ≥0.60. τ=0.3 (valor inicial del plan) dejaba
pasar 20 nodos de ruido para temas inexistentes — FAIL documentado y corregido.

## Preparación para prueba 1.3
El grafo tenía 0 asociaciones → se crearon 4 puentes cross-domain reales:
- SEGURIDAD.HBIT.PROTOCOLO ↔ OMEGA.HBIT.INTEGRACION
- HERMES.ARQUITECTURA.MCP ↔ SISTEMA.INFRAESTRUCTURA.HERMES_AGENT
- EVONY.GENERALS.RANGED ↔ PROYECTO.EVONYBOT...PLAN_MEJORAS_BOTS.MD
- SEGURIDAD.VERIFICACION.PARCIAL ↔ COMFYUI.MODELOS.COMPARACION

Nota de diseño: con τ=0.60, los pares casi-duplicados semánticos siempre tienen
ambos extremos ≥τ, así que el giro 3D solo se dispara cuando un extremo queda
fuera del hueco o debajo de τ. Se midieron scores de ambos extremos bajo varias
queries para elegir casos verificables (0.545/0.549 < τ vs 0.773 ≥ τ).

## PRUEBA 1.3 — giro 3D cruza dominios
Caso A→B: query='verificacion parcial de imagenes y archivos' k=20 τ=0.60
```
OUTPUT REAL: [2D] +0.773 SEGURIDAD.VERIFICACION.PARCIAL (score directo)
             [3D] +0.773 COMFYUI.MODELOS.COMPARACION via 3ed6fbf80d8aa4da
             (score directo del nodo COMFYUI = +0.545 < τ → SOLO entró por giro)
VEREDICTO: PASS
```
Caso B→A: query='que modelo de imagen tiene mejor calidad SDXL'
```
OUTPUT REAL: [2D] +0.790 COMFYUI.MODELOS.COMPARACION
             [3D] +0.790 SEGURIDAD.VERIFICACION.PARCIAL via 4ee6873c741c44db
             (score directo +0.598 < τ → SOLO entró por giro)
VEREDICTO: PASS (giro en ambas direcciones)
```
Bug corregido durante la fase: el presupuesto 3D (`k - len(nodes_2d)`) dejaba
0 slots cuando la fase 2D llenaba el hueco → los giros nunca entraban. Fix:
unión 2D+3D ordenada por peso(i,j)·s_i, top-k global (literal a F2).
